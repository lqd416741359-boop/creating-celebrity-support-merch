# 明星应援物生成器

## 目标

把人物名称或参考图转成可直接生成的饭圈应援物设计。依次确定人物来源、品类与配色，再把用户信息合并进对应模板并调用图像生成工具。

**REQUIRED SUB-SKILL:** Use `imagegen` for every actual image generation or edit.

## 人物来源菜单

先确定人物形象来源：

1. 上传参考图（推荐，人物一致性更好）
2. 只输入姓名，由 AI 生成（更快捷，相貌一致性可能较低）

按以下条件决定是否显示菜单：

- 用户已经上传目标人物图片：自动选择 1，跳过人物来源菜单并进入品类阶段；用户已明确品类时直接采用，否则显示周边菜单。
- 用户明确说“只用姓名”“不上传图片”或同义表达：自动选择 2 并进入品类阶段；用户已明确品类时直接采用，否则显示周边菜单。
- 只有人物姓名且未表达来源偏好：只显示上面的两项菜单并等待选择，不提前显示周边菜单。
- 在人物来源阶段选择 1 但尚未上传图片：只请求上传参考图；图片到达后进入品类阶段，不再次询问来源；此前已明确品类时直接采用，否则显示周边菜单。
- 在人物来源阶段选择 2：记录为姓名生成模式并进入品类阶段；此前已明确品类时直接采用，否则显示周边菜单。

不提供“AI 搜索人物图片”选项，也不主动联网下载或保存人物照片。

## 周边菜单

当用户尚未指定品类或编号时，只回复下面的菜单并等待选择；不要提前生图或逐项追问：

1. 应援手幅
2. 收藏小卡
3. 拍立得
4. 宣传海报／生日大屏
5. 四宫格明信片／歌词卡
6. 圆形吧唧
7. 演唱会纪念票

提示用户可回复一个编号或多个编号，例如 `4`、`2、6、7`。编号无效时重新显示菜单，不猜测。

## 配色菜单

用户选定品类后，如果尚未指定颜色，必须把 [assets/palette-guide.png](assets/palette-guide.png) 作为内联图片实际展示给用户，再显示下面的菜单并等待选择；不要只给文件链接、不要只写颜色文字、不要提前生图。该 PNG 中的连续横向色带就是配色菜单要求的真实色块预览：

1. 黑红银——主色黑、辅色红、银色点缀；舞台感、力量感
2. 蓝银白——主色深蓝、辅色银灰、白色点缀；清冷、未来感
3. 紫粉银——主色深紫、辅色粉、银色点缀；梦幻、浪漫
4. 黑金——主色黑、辅色金、暖白点缀；高级、典藏感
5. 白金香槟——主色象牙白、辅色香槟金、暖金点缀；温柔、轻奢
6. 绿银灰——主色森林绿、辅色银灰、米白点缀；清新、艺术感
7. 自定义颜色——请用户输入喜欢的颜色

预设配色按约 `60% 主色 + 30% 辅色 + 10% 点缀色` 合并进每条生图提示词。用户已经明确颜色时跳过本菜单。

编号按当前步骤解释：等待人物来源时，`1/2` 属于人物来源；等待品类时，编号属于品类；已经选定品类且正在等待配色时，单个编号属于配色。每次显示菜单时说明当前步骤并重复已经确认的信息，避免歧义。

## 生成流程

1. 从本轮和最近上下文提取：人物、参考图、人物来源状态、品类编号、配色编号、主题、文案、日期、颜色、风格。
2. 按人物来源菜单规则确定参考图模式或姓名生成模式。
3. 显示周边菜单并取得品类；若用户在同一句中已明确品类，则可直接采用。
4. 用户选择品类后，若未指定颜色则显示配色图和菜单；若已指定颜色则继续。
5. 读取 [references/templates.md](references/templates.md) 中对应品类与配色；多选时分别构造提示词，不混合版式。
6. 用户说“你决定”时，只授权自动补全主题、文案、风格和适合人物气质的配色；它不代替人物来源或周边品类选择。用户只说“直接生成”时，仅表示无需最终确认；它不能跳过尚未确定的人物来源、品类或配色。只有人物来源与品类均已确定，并且颜色已经确定或用户说“你决定”时，才调用 ImageGen。
7. 只有缺失信息会实质改变成品且无法安全默认时，才问一个简短问题。
8. 每个所选品类默认生成一张。调用 ImageGen 后直接展示结果，并用一句话说明采用的人物来源、品类、主题和配色。

## 人物与参考图

- 有上传参考图：把所有目标图纳入图像生成调用，要求身份、五官、发型和造型特征一致。
- 只有姓名：允许按姓名生成；在结果说明中提醒“未使用参考图，相貌一致性可能较低”。不要为了找图而主动下载或保存网络图片。
- 用户要求依据某张特定照片但照片未提供：请其上传；不得声称使用了该照片。

## 默认值

- 主题：人物纪念应援；不虚构代言、官方活动、场次或真实演出信息。
- 风格：高级饭圈美工、杂志排版、干净精致。
- 配色：用户选择菜单或直接输入颜色；只有用户说“你决定”时才根据人物服装与气质自动选择。
- 文字：人物姓名加简短纪念文案；模型难以可靠排长文字时，优先少字或无字底图。
- 输出：高清平面设计稿，无水印；多选时逐项生成，一类一张。

## 快速示例

用户：“帮我做刘亦菲的应援周边。”

回应：显示两项人物来源菜单并等待选择。

用户：“2。”

回应：记录姓名生成模式，显示七项周边菜单并等待编号。

用户：“4，你决定，直接生成。”

行动：读取模板 4，自动确定配色与纪念文案，调用 ImageGen 生成宣传海报，不再追问。

## 常见错误

| 情况 | 正确处理 |
|---|---|
| 未选编号就生图 | 先显示菜单并等待 |
| 把 `2、6、7` 合成一张 | 按三种模板分别生成 |
| 用户说“你决定”后继续问颜色 | 使用默认值并生成 |
| 只有姓名却声称用了参考照片 | 明确未使用参考图 |
| 已选品类但未给颜色就直接生成 | 显示配色参考图和七项菜单 |
| 配色阶段把 `2` 当成收藏小卡 | 按当前步骤解释为蓝银白 |
| 只有姓名就直接显示周边菜单 | 先询问两项人物来源 |
| 人物来源阶段把 `1` 当成手幅 | 请求用户上传参考图 |
| 人物来源阶段把 `2` 当成小卡 | 记录姓名生成模式，再显示周边菜单 |
